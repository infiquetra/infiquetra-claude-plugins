through a `gh` child, and a land must not wait on the network. What does not hold is the docstring's
conclusion that "the vocabulary still has exactly one source". Mission Control resolves GitHub `main`

pre-#927 single-string override made `land` exit 0 at base and exits 2 now, measured head against base
