## The defect the cycle spent itself on

Three lenses reached it independently, by three different routes, and the coordinator reproduced each
mechanism. The repair decides the input box by taking `classified[-1]` — the last block it can
*classify*, not the last block. Both supported vendors draw an empty box inside a styled span that
closes, which is precisely the unclassifiable case, so the real box drops out of the candidate list
and a scrollback echo above it supplies the verdict.

  live box row (unclassifiable) --> dropped --> classified[-1] = the echo above --> "staged"

Measured on 43 live panes with both revisions against byte-identical captures:

| Verdict over 43 live panes | cycle 2 `cbc2fa19` | cycle 3 `a7ba2995` |
|---|---|---|
| `empty` | 34 | 13–14 |
| `unreadable` | 8 | 26–28 |
| `staged` | 1, genuine | 2–3, of which 1–2 false |

Two further properties compound it. A block has no closing rule — the accumulator is never reset — so
a block opened at an echo absorbs 10 to 18 transcript rows and reports them as the operator's staged
text; and the block is discontiguous, because a styled row is skipped rather than ending the block, so
non-adjacent rows join. The character count the guard withholds is therefore not the length of
anything in the box.

The guard also cannot see the box at all on five of the seven vendors the plugin drives:
`_COMPOSER_GLYPH_BY_VENDOR` maps two. The run's own live capture records grok drawing the decorated
glyph the table does not give it.
