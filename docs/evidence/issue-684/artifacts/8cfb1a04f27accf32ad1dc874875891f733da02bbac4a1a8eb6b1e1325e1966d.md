**#1 — Tautological third-leg proof in the re-add guard (testing, 75, advisory).**
Evidence: `tests/test_no_lease_broker_readd.py:145-159` builds `fake_root = tmp_path / "fake-plugins" / "fleet-core" / "scripts" / "fleet_commons"` with `lease_broker.py` containing `import lease_broker  # stale cache`, then `assert _scan_tree(PLUGINS) == []` and `assert offenders == [fake_root / "lease_broker.py"]` — both real — followed by `assert fake_root in [fake_root]` (159). The comment at `:157-158` claims “this test proves the guard's second leg exists” but the assertion is `x in [x]` for a locally built path, never touching `_shim_resolved_paths()`. The property (guard scans shim-resolved paths) is covered by `test_no_file_under_plugins…:130-133` which loops `for resolved in _shim_resolved_paths(): assert _scan_tree(resolved)==[]`, so the tautology does not weaken the guard's correctness — it only misdocuments the third test's intent. Suggested fix: replace the tautology with `assert any(p == fake_root or p.is_relative_to(fake_root) for p in [_shim_resolved_paths(), [fake_root]][1][0:1])`-like or, more honestly, assert that the helper *could* return an out-of-tree path by injecting a fake shim root into `_shim_resolved_paths` and asserting it appears, or delete the line and rename the test to “tree vs out-of-tree distinction”. Owner: human (test prose, not runtime). Route stays advisory — not P0/P1.

**#2 — Retired `--lease-store` flag lacks deprecation surfacing (maintainability, 75, advisory).**

Suggested fix: add `help="… (retired #677/U7 — broker deleted, always absent; retained for compatibility)"` and optionally emit a `warnings.warn` or `report["warnings"]` entry when a non-default lease store is supplied.
