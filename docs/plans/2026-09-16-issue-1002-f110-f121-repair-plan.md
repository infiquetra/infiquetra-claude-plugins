# Agent Launcher F110/F121 repair after 1.5.0

Implement issue 1002 R5 and R13 as already written. 1.5.0 shipped adjacent-only decoys and a detector that still only matched `run([str,str,str])`. This repair makes blank-separated empty markers stay `STAGED`, keeps the content-row echo case `EMPTY`, and makes the production `_raw_door_calls` helper report the enumerated evasion shapes.

## Problem Frame

Parent issue 1002 and its twenty-one children closed on squash-merge `da38af8a` (PR #1013, Agent Launcher 1.5.0). A post-merge skeptic showed two HIGH gaps against the plan that already shipped:

- F110 / #961 / R5: `inspect_composer('❯ staged draft\n\n❯ ')` is `EMPTY` and `inspect_composer('❯ staged draft\n❯ \n❯ ')` is `UNCLASSIFIABLE`. Both authorize a write. The 1.5.0 walk handled one immediately-adjacent empty marker and broke after the previous block.
- F121 / #972 / R13: production `_raw_door_calls` still only matched `run([str,str,str])`. `test_structural_detector_kills_enumerated_evasion_shapes` special-cased concat / `HERDR` / `w.write` so those cases passed without reporting a stray door, and reimplemented detection instead of driving the helper that walks `launcher.py`.

CORR-05 (`❯ earlier submitted prompt\npane output line\n❯ `) already stays `EMPTY` and must stay that way.

## Requirements

R1. `inspect_composer("❯ staged draft\n\n❯ ", vendor="claude")` returns `STAGED` with text `staged draft`. (#961 F110, plan R5)

R2. `inspect_composer("❯ staged draft\n❯ \n❯ ", vendor="claude")` returns `STAGED` with text `staged draft`. (#961 F110)

R3. `inspect_composer` / `composer_staged_text` on `❯ earlier submitted prompt\npane output line\n❯ ` stays empty (CORR-05). A content row between a staged echo and a last empty marker is last-block-wins.

R4. `_raw_door_calls` reports a stray door or inline predicate for every snippet in the repair finite test plan, including `subprocess.run`, argv locals, tuples, list concat, assigned constants, f-string element 0, aliases, keyword `args=`, `writer._raw`, inline `if not session_owned` / ternary, and `w.write`. (#972 F121, plan R13)

R5. `test_structural_detector_kills_enumerated_evasion_shapes` asserts `_raw_door_calls(ast.parse(snippet))` is non-empty for every parametrized snippet. It has no special-case `return` and does not reimplement detection.

R6. `test_every_pane_write_goes_through_the_one_writer` still walks the same `_raw_door_calls` over `launcher.py` and `orchestrate.py`. False positives on `exclude_file.write` and `close_run_session`'s `if session_owned` stay absent.

R7. Agent Launcher version is `1.5.1` with `plugin.json` / marketplace `agent-launcher` entry / `CHANGELOG.md` parity. Orchestrate's companion floor stays `>=1.4.0`. The hardcoded current-version pin in `tests/test_agent_launcher_plugin.py` moves with the triad.

## Key Technical Decisions

KTD1. Blank-only (or intermediate empty-decoy) separation is a decoy; a leftover content row is scrollback. Walk trailing empty markers from the tail until a `STAGED` block whose interval is blank-or-decoy, then return that staged inspection. Break on a content row so CORR-05 stays `EMPTY`. Rejected: adjacent-only (1.5.0 first landing). Rejected: any earlier staged block regardless of content between (refuses a working launch).

KTD2. The detector that walks production files is the detector the snippet test asserts. Broaden `_raw_door_calls` (and its `_argv_head` / `_assigned_values` / `_run_aliases` helpers) to the finite-test-plan shapes. Drop special-case returns in the snippet test. Narrow `Name.write` to `{w, pw, pane_writer}` or a `PaneWriter`-bound name that is not `writer`, and `session_owned` only when the body mentions `guard_pane` / `.write(` / `._raw` / `._type` / `'herdr'`, so `exclude_file.write` and `close_run_session` are not false positives. Rejected: a second snippet-only detector. Residual `getattr` / `sys.modules` dynamism stays residual (original KTD9).

KTD3. Patch-release 1.5.1, floor stays 1.4.0. This repair changes classification and the structural net of functions Orchestrate already imports. It does not add a public name. `{#907-agent-launcher-floor-owner}` applies.

## Implementation Units

### U1. Blank-separated decoy walk

`inspect_composer` returns the earlier `STAGED` block when the last block is an empty decoy and every row between them is blank or another empty decoy.

**Goal:** The two skeptic dumps classify `STAGED`. The CORR-05 dump stays empty.

**Requirements:** R1, R2, R3

**Dependencies:** none

**Files:** `plugins/agent-launcher/skills/agent-launcher/scripts/composer.py`, `plugins/agent-launcher/tests/test_launcher_contract.py`

**Approach:** Keep `_composer_blocks` as 1.5.0 left it. In `inspect_composer`, if the last classified block is an empty or unclassifiable-empty decoy (`_is_empty_decoy`), walk earlier blocks. Skip intermediate empty decoys. When a `STAGED` block is found, return it only when `_only_blanks_between` is true for the interval, treating intermediate decoy rows as ignorable. A leftover content row breaks and last-block-wins. Adjacent blocks have an empty interval and stay `STAGED`.

**Patterns to follow:** original plan U1 Approach ("every row between it and a previous STAGED block is blank"); `{#1002-decoy-empty-marker}`.

**Test scenarios:** TP-F110c, TP-F110d, TP-F110b.

**Verification:** `inspect_composer("❯ staged draft\n\n❯ ", vendor="claude").state` is `STAGED`. `inspect_composer("❯ staged draft\n❯ \n❯ ", vendor="claude").state` is `STAGED`. `composer_staged_text("❯ earlier submitted prompt\npane output line\n❯ ", vendor="claude")` is `""`.

### U2. Production detector reports enumerated evasions

`_raw_door_calls` is the net `test_every_pane_write_goes_through_the_one_writer` uses. The snippet test drives that helper with no special-cases.

**Goal:** Every repair-plan snippet yields a non-empty `_raw_door_calls` result. Production files stay clean of false positives.

**Requirements:** R4, R5, R6

**Dependencies:** none

**Files:** `plugins/agent-launcher/tests/test_launcher_contract.py`

**Approach:** Resolve argv through List/Tuple/Name/BinOp-Add/JoinedStr/assigned constants/aliases/`args=`/`subprocess.run`. Report `._raw`/`._type`. Report `w`/`pw`/`pane_writer`.write and a `PaneWriter`-bound name that is not `writer`. Report `If`/`IfExp` containing `session_owned(` only when the unparsed body also mentions `guard_pane`, `.write(`, `._raw`, `._type`, or a `'herdr'`/`"herdr"` token. Parametrize `test_structural_detector_kills_enumerated_evasion_shapes` over the snippet table and assert `_raw_door_calls(tree)` is truthy. Do not special-case concat, `HERDR`, or `w.write`.

**Patterns to follow:** original plan U2 Approach; existing `test_every_pane_write_goes_through_the_one_writer`.

**Test scenarios:** TP-F121, TP-F121b.

**Verification:** `_raw_door_calls(ast.parse("run([f'herdr','pane','run','p','t'])"))` is non-empty. `_raw_door_calls` on current `launcher.py` still reports exactly two doors inside `PaneWriter`.
