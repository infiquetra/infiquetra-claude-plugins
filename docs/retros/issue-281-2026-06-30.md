## Findings

### F1 — Gemini 3.1 Pro (High) first-run fix profile (the operator's headline ask)

3/3 delegated units were **functionally correct on first apply** (their suites passed). Everything Claude
had to fix fell into **three buckets**, only one of which was substantive:

1. **Cosmetic lint (ruff)** — `N818` exception class needs `Error` suffix (`DeadlineExceeded` →
   `DeadlineExceededError`), `SIM105` (`try/except/pass` → `contextlib.suppress`), `SIM108` (if/else →
   ternary), `F401` (unused import), `W293` (trailing whitespace on blank lines), `E402` (sys.path-mediated
   sibling imports in the seam test need `# noqa: E402`). Zero-logic, mechanical.
2. **Wrong-domain enum guesses (semantic, but caught by the build)** — agy invented *plausible* saga enum
   values it couldn't know: `lifecycle_phase="planning"` (canonical `"plan"`), `phase_status="in-progress"`
   (canonical `"in_progress"`), `status="ready"` (canonical `"active"`). The real `Saga` construction +
   tests rejected them. **Pre-emption:** hand canonical enum members in the task packet.
3. **One real robustness edge MISSED (the only logic fix)** — U2's orphan sweep globbed `*.json` only and
   had no immediate temp cleanup, so a `.tmp` stranded between `write_text` and `os.replace` (deadline
   firing mid-write) would leak. Fixed in `6f50d14`: track `tmp_path` outside the `try`, reclaim it in the
   `except`, broaden the TTL sweep to `iterdir()`. Surfaced by `/code-review` (P3), not by agy.

**Takeaway:** for bounded well-specified units, Gemini-3.1-Pro's failure surface is lint noise + domain-
vocab guesses; the rare logic gap is an atomic-write / crash-safety edge — exactly the kind a verify gate
(not the author) catches.
